Courier Platform — API Documentation

Interactive Swagger UIs for all 10 microservices  ·  Start the platform with docker compose up

Make sure the containers are running before clicking Open Swagger. Services that require a JWT — open user-service first, register and log in, then click Authorize in the other UIs and paste the token.

Core services
NestJS :3001

user-service

Identity & auth — register, login (JWT issued here), profile management, rider registration & vehicle management.

Open Swagger
NestJS + Socket.IO :3002

trip-service

Full trip lifecycle — create, broadcast, accept, start, complete, cancel, dispute. Real-time updates via ws://localhost:3002/trips.

Open Swagger
FastAPI · Python :3003

pricing-service

ML fare prediction — scikit-learn regression model. No auth required. Inputs: distance, duration, vehicle type, time, weather.

Open Swagger
NestJS :3010

delivery-service

Parcel lifecycle — create, assign, pickup, transit, deliver, COD collection/remittance. Public tracking at GET /track/:number.

Open Swagger
Infrastructure services
NestJS · Redis :3004

geo-service

Live rider positions backed by Redis. No auth. Used by matching-service to find nearby riders. Positions are ephemeral.

Open Swagger
NestJS · Postgres :3006

payment-service

In-platform wallets — open account, top up, hold/release/refund funds. Called automatically by trip-service on trip events.

Open Swagger
Stub & event-driven services

No REST API — consumes trip.created events and dispatches offers to nearby riders via geo-service. See docs for the flow.
